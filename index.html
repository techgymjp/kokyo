皇居ランナー

ロードバイクで皇居を一周（約6km）。
ランナーや歩行者、車やバイクをよけながら、二重橋前のゴールをめざせ！

二重橋前 → 大手門 → 竹橋 → 九段下 → 田安門（武道館）→ 千鳥ヶ淵 → 半蔵門 → 三宅坂 → 桜田門 → 二重橋前

  • ステージは 朝 → 昼 → 夕方 → 夜 の順に、人も車も増えて難しくなります。ゴールすると次のステージが開きます
  • ふだんは自動で時速40kmまでこぎます。ダッシュは体力を使い、ゼロになるとできません（離すと回復）
  • 坂は実際の標高どおり。九段坂は上りで遅く、三宅坂の下りは時速80km！
  • 歩行者・ランナー・車・バイクにぶつかったらゲームオーバー。2人組・3人組の間はすり抜けられません
  • 都道301号（祝田橋〜大手門〜竹橋）は一方通行。左の1車線がランナー、ほかの車線は後ろから車が来ます。ほかの区間は対向車線から車が来ます
  • 昼・夕方・夜のステージは、後ろから雲に乗った鬼が追いかけてきます。捕まったらアウト
  • 桜田門の手前では、井伊直弼の行列が横断中…？ 隙間をすり抜けろ
